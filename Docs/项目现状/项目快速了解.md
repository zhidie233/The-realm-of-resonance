# 《共鸣之境》项目快速了解

Unity 联机第一人称射击游戏。玩家对局里的命中、误伤、打设施、夺旗都会改变一个全局共鸣值，共鸣值越过阈值就改变战场条件：跳跃重力、地面火海、第三阵营机器人、空投补给、陨石打击。

本文按当前代码状态整理，2026-11-27。仓库根目录 `Project/` 是 Unity 工程，`Docs/` 放文档。

## 一、玩法构成

| 项 | 内容 |
| :--- | :--- |
| 模式 | 团队竞赛 `TeamMatch`、自由混战 `FreeMatch`、夺旗 `CaptureMatch` |
| 阵营 | 蓝队、红队，另有第三阵营机器人参与搅局 |
| 武器 | 8 把，统一走武器表配置 |
| 兵种 | 4 类：`Vanguard`、`Pathfinder`、`Guardian`、`Artificer`，各四槽位 |
| 房间 | 人数 2 至 16，目标阈值与单局时长在建房时选，团队与混战可开 AI 补位 |

八把武器的当前配置值，来自 `Assets/Config/Modules/WeaponCatalog.asset`：

| 名称 | 类型 | 伤害 | 间隔 | 换弹 | 射程 | 精准 | 负重 |
| :--- | :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| Rifle | Machinegun | 25 | 0.09 s | 2 s | 700 | 1 | 2.0 |
| Pistol | Pistol | 25 | 0.25 s | 1.5 s | 300 | 3 | 1.95 |
| Shotgun | Shotgun | 50 | 1.25 s | 6 s | 100 | 1 | 2.2 |
| Grenade | Grenade | 80 | 2 s | 2 s | 125 | 1 | 1.7 |

## 二、共鸣系统

共鸣值是整局唯一的中枢数值，房主端结算，写入房间属性 `rr.resonance`，其余客户端在属性回调里接收。

| 触发 | 权重 |
| :--- | :--- |
| 命中敌方 / 误伤友方 | +1 / −1 |
| 共鸣增幅器 / 抑制器 | +2 / −2 |
| 夺旗 / 交旗 / 归还 | +10 / +20 / −5 |

下游六个配置资产由 `ResonanceSuite.asset` 统一挂接，实际生效的五类响应：

| 模块 | 行为 | 当前参数 |
| :--- | :--- | :--- |
| `GravityManager` | 按曲线改写本地角色跳跃初速度，移动重力设施 | 曲线映射到 −25 至 35 |
| `GroundFireManager` | 火点激活与销毁 | 阈值 150，伤害随共鸣上升 |
| `RobotManager` | 刷第三阵营机器人 | 每跨 1000 一点 |
| `SupplyManager` | 投放补给箱 | 每跨 200 一次 |
| `MeteoriteFacility` | 击中设施后召唤陨石 | 下落速度 20、基础伤害 50、倍率 1 至 3 |

代码位置在 `Assets/Code/Runtime/Anomaly/`，类名与房间键用 Resonance。

## 五、配置体系

配置由根资产加五个模块资产组织，编辑器里改配置不用碰脚本。

| 资产 | 内容 |
| :--- | :--- |
| `ProjectConfigRoot.asset` | 根，指向下列模块 |
| `Modules/MatchRules.asset` | 战斗开关、流程参数、计分规则 |
| `Modules/WeaponCatalog.asset` | 武器表与槽位引导 |
| `Modules/ArenaCatalog.asset` | 地图清单与各模式的目标阈值 |
| `Modules/FactionRoster.asset` | 双方名称配色、玩家与机器人预制体 |
| `Modules/ResonanceSuite.asset` | 共鸣开关与六份环境配置 |

`MatchRules` 里几个能直接改到体验的字段：出生保护 5 秒、复活等待 7 秒、开局倒计时 3 秒、命中检测步长 3 帧、模拟弹道开、掉枪开、自动回血开、`buildVersion` 1.0.0。

## 六、关键实现

### 网络同步

四类通道分工。位姿走 `IPunObservable` 序列化加插值；一次性动作用 `[PunRPC]`，当前代码里 28 个；不挂网络视图的广播走 `RaiseEvent`；房间公开状态写房间属性。

事件码集中在 `NetProtocol.cs`，当前编号 10 至 22，共 13 个：

| 码 | 用途 | 码 | 用途 |
| ---: | :--- | ---: | :--- |
| 10 | 准备就绪 | 17 | 武器拾取 |
| 11 | 等待厅初次同步 | 18 | 投票 |
| 12 | 开局 | 19 | 夺旗 |
| 13 | 聊天 | 20 | 空投 |
| 14 | 击杀播报 | 21 | 门 |
| 15 | 道具实例 | 22 | 倒计时 |
| 16 | 道具变更 | | |

房主中途退出时由 `OnMasterClientSwitched` 回调接管计时与场内全部机器人。

### 战斗

`ShotController` 继承 `ProjectileBase`，用二阶 Heun 法在物理固定帧推进弹道坐标，不给子弹挂刚体；每隔固定帧数做一次分段射线采样，命中后分四路处理：玩家骨骼按头胸臂腿倍率扣血、机器人直接扣血、共鸣设施触发变更、墙体贴弹孔并把子弹还池。命中检测步长由 `MatchRules.combat.hitTestFrameStep` 控制，当前 3。

刀用 `SphereCast` 判伤，手雷与燃烧瓶是抛物线投掷，榴弹发射器带障碍遮挡校验的爆炸伤害。角色侧有布娃娃、死亡观战、出生保护三段流程。

### 机器人

`AIBotAgent` 在七个状态间迁移：待机、巡逻、跟随、掩护、观察、搜寻、驻守；配三种行为模式：激进、被动、保护。掩体由 `AICoverSpotManager` 调度，占用与冷却成对出现。寻路与状态机只在房主端算，其他端拿同步数据插值，开火换弹走 RPC。

### 渲染

主相机设为 Base，武器相机设为 Overlay 并挂进相机栈，配自研前景着色器解决第一人称枪模穿墙。河道水体用屏幕坐标与深度图差值算水深，叠双层反向滚动法线。`PostProcessEffects.cs` 运行时开关 Bloom、色差、动态模糊，SSAO 通过反射从渲染器特征列表里取。

## 七、场景与运行

| 场景 | 用途 |
| :--- | :--- |
| `MainMenu` | 入口，大厅与建房 |
| `OldQuarter` | 对战地图「小镇」 |
| `Test` | 机制验证地图「测试」 |
| `EmptyScene` | 空场景 |

构建配置里启用了前三个。`ArenaCatalog` 把「小镇」映射到 `OldQuarter`，把「测试」映射到 `Test`。

`OldQuarter` 是主要地图，场景文件 1.2 MB，内含双方出生点、掩体点、可拾取武器点、门体、梯子、共鸣设施与空投区域，NavMesh 已烘焙。按场景文件里的组件引用粗数，掩体点约 28 处、火点约 45 处。

运行方式：Unity 打开 `Project/`，进 `MainMenu` 播放。连外网时用 Photon 云端房间；没有外网时开离线房间模式，`PhotonNetwork.OfflineMode` 建本地房间做单机调试。
