# 游戏框架教程：添加武器

## 武器动画

### DrawWeaponModel

添加新武器当然需要武器的 3D 模型。添加新武器有几种做法，有些人只替换武器模型，沿用游戏框架默认的手部模型和动画*（本质上是把新武器模型摆到手中）*。这虽然不算错，但绝非最佳方案，因为游戏框架的手部模型和动画只是示例占位，换成不同武器模型后动画效果并不理想。
 
强烈建议使用你自己的模型和动画*（包括手臂模型）*。可以沿用游戏框架默认手部，但这样需要为每一把要添加的武器单独做动画；若不擅长动画制作，会相当吃力，因为**至少需要 4 个动画：掏出、收起、开火、换弹**。
 
**另一种选择**，若想省时省力，可以购买兼容框架的武器模型包，自带所需动画和配套手臂模型。可在资源商店中按需挑选。

### DrawCreateInfo

添加新武器的第一步是创建武器信息，打开 **GameData**，在 'AllWeapons' 列表中新增一项。

此时 GameData 应在检视面板中打开，在检视面板底部可以看到 'Weapon' 区段及 'AllWeapons' 列表，展开该列表并**新增**一项。
*（使用下方按钮）*

此时 'AllWeapons' 列表中会出现名为 **'New Weapon'** 的新项，展开并按所添加武器类型填写信息。

- **Name**（string）：这把武器的名称。请为每把武器使用唯一名称，便于区分。

- **Type**（enum）：该武器的类型，例如狙击枪、步枪、匕首等。

- **Damage**（int）：该武器每次命中造成的伤害值。

- **射速**（float）：两次射击之间的最短间隔。

- **装弹时间**（float）：装填该武器所需时间。

- **Range**（int）：该武器子弹在被销毁前可飞行的最大距离，也是可能命中目标的距离。

- **Accuracy**（int）：子弹的散布范围。

- **Weight**（int）：该武器的重量。启用这把枪时，重量会影响玩家移动速度

- **拾取预制体**（GunPickUp）：该武器的拾取预制体。此处暂时留空，本教程后面会设置。

- **枪械图标**（Sprite）：代表该武器的精灵图图标。

以下是 **GunController** 脚本可调属性的简要说明

- **瞄准平滑**（float）：从默认位置过渡到瞄准位置的速度。

- **瞄准延迟移动**（float）：瞄准时延迟移动效果的程度。

- **瞄准视野**（float）：瞄准时相机的视野，即变焦程度。数值越小变焦越大。

- **Bullet**（string）：在此填写该武器发射的池化子弹名称。

- **Muzzleflash**（ParticleSystem）：该武器射击时的枪口火焰粒子效果。需为默认实例化的对象。

- **Shell**（ParticleSystem）：模拟射击时抛出弹壳的粒子效果。

- **冲击力**（int）：子弹击中刚体时施加的作用力

- **震屏配置**（Scriptable）：ShakerPresent.cs 的 ScriptableObject，其中包含射击时震屏效果的全部设置

- **Recoil**（float）：开火时的枪身后坐幅度。

- **后坐恢复速度**（float）：相机从后坐状态恢复的速度。

- **自动装弹**（bool）：弹药为 0 时是否自动装弹？

- **每匣弹药量**（int）：该武器一个弹匣可装多少发子弹。

- **Ammo Per Clip**（int）：该武器默认拥有多少个弹匣。

- **装弹方式**（enum）：Bullets 表示逐发装填直至装满，适用于部分霰弹枪与狙击枪；Clip 表示一次性更换整个弹匣。

- **开火延迟**（float）：仅用于手雷，从按下输入到投出投射物的延迟时间

- **散布范围**（MinMax）：子弹散布的范围，实际数值会在给定的最小值和最大值之间随机取值。

- **瞄准散布倍率**（float）：使用该武器瞄准时，散布会乘以该值。0.5 表示正常散布的一半

- **每秒散布增量**（float）：持续开火时散布每秒增加的量。

- **每秒散布衰减量**（float）：停止开火后散布每秒减少的量。

- **按动画播放装弹音效**（bool）：装弹音效是按动画关键事件播放 手动，还是按时间计算触发 自动？

- **OnNoAmmoDesactive**（Array）：仅用于手雷。把手中持有的所有投射物对象加入该列表。

最后，若该武器是狙击枪，还需添加 SniperScope.cs 脚本，指定瞄准镜贴图，并在 'OnScopeDisable' 列表中加入狙击模型的所有网格，包括手部。

最后，在武器的 **GunController** 检视面板底部可看到 **添加到列表** 按钮，点击后该武器会自动加入 **GunInventory** 的 **AllWeapons** 列表。

若该按钮未出现，请确认武器已在列表中：选中 **WeaponsManager** -> **GunInventory** -> **Gun List** -> *检查武器是否在列表内*。

若不在列表中，可手动在列表里新增一项并把新武器拖到该字段上。

若想将其设为某个玩家兵种的默认武器，只需（仍在 GunInventory 中）展开目标兵种区域，即突击兵、支援兵、侦察兵或工程兵，在需要的槽位中选择，槽位包括主武器、副武器、匕首或投射物，选择该武器的名称。

接着保存或应用对玩家预制体的修改（暂时不要从场景中删除玩家，下一步还要用到）。

完成，你已添加了一把新的第一人称武器。

### DrawTPWeapon

每把武器有两个视角：**第一人称视角**是本机玩家看到的，**第三人称视角**是其他玩家看到的。本部分配置后者，即**第三人称武器**。所需的模型与第一人称武器相同，但不含手部或手臂，只保留武器本体网格。不过**建议使用比第一人称模型更精简、面数更低的模型。**

若你是从上一步继续，场景中应仍有玩家预制体；若没有，请把添加了第一人称武器的那个玩家拖入场景层级。

然后打开 ***PlayerNetworkHandler*** 检视面板，点击 **Network Guns** 列表中的某个脚本，层级会展开到所有第三人称武器的位置。把武器模型拖入 **RemoteWeapons** 对象中。

调整武器对象的位置，模拟玩家用手握住武器的样子。

若你的玩家模型处于 T-Pose 或某个姿势，难以把武器摆到手上时，可以打开 **Animation** 窗口，选择 idle 待机动画并跳到其中某一帧。这样玩家会处于该动画姿态，你就比较容易摆放枪械了。

选中刚拖入玩家的那个武器模型，添加脚本 **RemoteGun.cs**

在脚本检视面板中可看到一个名为 'Local Weapon' 的空字段，以及一个列出该玩家预制体中所有第一人称武器（GunController）的下拉框。按对象名选中你先前设置好的第一人称武器，然后点击 Select 按钮。

点击该按钮会自动指定所选的第一人称武器，脚本检视面板中会出现一些新的变量：

- **MuzzlefFlash**（粒子系统）：开火粒子效果。

枪口火焰方面，把你的粒子特效拖入武器对象内；若没有自己的，框架默认特效位于：Assets/Prefabs/Level/Particles/Prefabs/Misc/MuzzleFlashEffect。把它拖入层级，放进武器内部并摆到枪口末端。然后在 MuzzleFlash 字段中指定它。

对于手雷，检视面板会多出一个名为 'Bullet' 的字段，需把 手雷预制体 拖入其中。

脚本检视面板中有一个 **'设置手部 IK'** 按钮，点击后会打开一个小编辑器窗口，Scene 视图。你会看到选中了一个球形辅助图标。移动它时左手会跟随运动，受 IK 约束。因此把它移动和旋转到 左手应在的位置，让持枪姿势更真实。
 摆好之后，点击先前打开的小窗口中的 DONE 按钮。

最后点击检视面板中的 登记第三人称武器 按钮，即可将该武器自动加入网络武器列表。

完成，第三人称武器已添加。别忘了保存或应用对玩家预制体的修改。

### DrawExportWeapons

武器系统提供了一个实用功能，即武器配置的**导出**与**导入**。这里所说的武器配置指某个玩家预制体中武器的第一人称武器、第三人称武器、枪械信息、位置、旋转等数据。

当你需要把武器从一个玩家预制体迁移到另一个，甚至迁移到另一个 Unity 工程时，这个功能尤其有用。例如，你刚在玩家预制体 1 中集成了新武器，也想在玩家预制体 2 中集成它；既然在玩家 1 中已配置完成，就不必在玩家 2 中重复全部步骤，只需从玩家 1 导出配置再导入玩家 2 即可，这样一把武器只需集成一次，很省事。

言归正传，第一步是从已集成该武器的玩家预制体中导出武器。打开该玩家预制体，拖入场景层级或在预制体场景中打开均可，然后选中第一人称武器（位于 WeaponManager 下），在 GunController.cs 检视面板顶部可看到 **导出** 按钮，点击它。随后会弹出一个小窗口，点击其中的 **导出武器** 按钮，接着弹出对话框选择导出武器的保存文件夹，选择你希望保存的位置即可。

导出完成后，就可以导入到任意玩家预制体了。打开要导入武器的玩家预制体，这次选中 **WeaponManager** 对象，在 GunInventory 检视面板中点击右上角的 **导入** 按钮。随后会打开新窗口，其中有一个 **待导入武器** 空字段，把你刚保存的 **导出武器** 预制体拖入该字段，点击 **导入** 按钮即可。

这样该武器就完整集成到这个玩家预制体中了。

### AnimateWeapon

关于武器最常见的问题之一是如何为武器制作动画。如前所述，要在游戏框架中为第一人称视角集成一把新武器，你需要：
 
•  手臂或手部模型
•  武器模型
•  4 个动画**（掏出、收起、开火、换弹）**
 
无论你使用游戏框架示例手臂模型还是自定义模型，都需要自己或由美术为它们和新武器模型制作动画；**这一过程与游戏框架无关**，简单来说就是**按你为游戏中任何其他对象或模型做动画的方式来做即可**。游戏框架对武器动画的制作方式没有任何限制，你可以在任何顺手的工具中制作，Unity 内部或 Blender、Maya、3ds Max 等第三方软件皆可。

### ShowWindow
