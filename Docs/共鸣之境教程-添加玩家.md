### DrawRagdolled

模型就绪后即可开始配置。
 
首先要为新玩家模型制作布娃娃。在 Unity 中通常通过 GameObject ➔ 3D Object ➔ Ragdoll 手动创建，并在向导窗口中逐个指定骨骼，而本工具可自动完成，你只需把玩家模型拖到下方。

从 **Project 视图** 中将玩家模型拖到此处

已具备创建布娃娃的条件，点击下方按钮进行构建。

此时你的玩家模型*（场景中）*应大致如下：

这些 **Box** 和 **Capsule** 碰撞体就是玩家碰撞盒*（检测子弹命中玩家的碰撞体）*。某些模型上这些碰撞体可能位置或朝向不正确，导致游戏中玩家的部分身体无法被命中。

因此请确认所有碰撞体完整覆盖玩家模型，必要时调整碰撞体参数。

确认无误后即可进入下一步。

> 旧模型不会自动删除，以防两个模型在位置、缩放或旋转上存在明显差异。若有差异，可以旧模型为参照手动调整新模型的位置、旋转和缩放；若一切正常，直接删除旧模型即可。

有一处需要手动处理。
 
第三人称武器*（TPWeapons）*已从旧玩家模型迁移到新模型，但模型之间的局部坐标轴朝向往往不同，因此这些武器在新玩家手中的位置和朝向不会正确，需要手动调整。可以先调整 **第三人称武器根节点**，也就是所有第三人称武器的父节点，即名为 **RemoteWeapons** 的对象。
 
以下是替换玩家模型后武器可能出现的样子*（大致如此）*：

> 玩家会自动摆出 ***瞄准姿态***，便于调整武器位置。即便你的玩家外观与下图不同，原理一致：**像玩家双手握持那样摆放武器。**

要调整位置和朝向，请选中玩家预制体中的 **RemoteWeapons** 对象*（位于玩家模型的右手下）*，或点击下方按钮尝试在层级面板中自动定位它。

此时 RemoteWeapons 对象应在层级面板中被选中并框显。为方便预览武器位置，若当前没有启用或显示任何武器，请从 *RemoteWeapons* 对象中选择一个并启用它以显示；若已启用多个，建议全部禁用只保留一个，便于观察。

然后重新选中 **RemoteWeapons** 父节点*（不是某个武器子节点）*，旋转或移动它，使武器看起来像被玩家握在右手中，效果大致如下：

> 玩家会自动摆出 ***瞄准姿态***，便于调整武器位置。即便你的玩家外观与下图不同，原理一致：**像玩家双手握持那样摆放武器。**

> 你也可以在层级中启用某把第三人称武器 *位于 RemoteWeapons 的 Transform 下* 来查看其外观，并按新玩家逐把微调，使姿态更准确。

**瞄准位置**

武器位置调整完成后，同样只保留一个第三人称武器处于激活状态以便预览姿势。
 
手臂瞄准位置由 IK 控制，可在检视面板中自定义。选中玩家预制体中带 **(NEW)** 标记的玩家模型，它位于 RemotePlayer 对象内 ➔ 打开检视面板 ➔ PlayerIK ➔ 在脚本检视面板底部 ➔ 点击 **预览瞄准位置** 按钮 ➔ 移动自动选中的轴心点，可看到手臂随之移动 ➔ 将轴心点放到你想要的瞄准位置 ➔ 确定后点击黄色的 **完成** 按钮即可。

> 请确保编辑器中已启用 **Gizmos**，否则无法移动轴心。

完成后，如果还没有删除旧模型，现在请删除：

现在需要将该预制体复制到 **Resources** 文件夹，拖到 Assets/Resources 即可，可按需重命名。

接下来需要将该新玩家预制体分配给某个阵营使用（阵营 1 或阵营 2）。打开 GameData（同样位于 Resources 文件夹）-> Players 区段，在对应字段（Team1 或 Team2）中指定，拖入新的玩家预制体。

完成，新玩家模型已集成！

 请注意：部分模型与默认玩家动画的重定向并不完全兼容，会导致会导致部分动画看起来不自然。遗憾的是无法自动修复。你有两个选择：编辑该动画，或替换成你确认 可用的动画。关于如何替换动画的更多信息见文档。

希望提供多个玩家选项供玩家挑选？需要自行扩展玩家选择功能，可接入任意数量的玩家模型。
