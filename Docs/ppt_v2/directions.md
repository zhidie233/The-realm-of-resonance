# 《共鸣之境》三方向设计卡（6 个候选 → 3 套完整初稿）

## 入选完整版（3 套互不撞骨架、互不撞色温）

### 方向 1（dir-1）：新瑞士声学大字报 · 极高反差浅色
- **逻辑与来源**：最佳设计师（Josef Müller-Brockmann 瑞士网格）× 现实参照（`ppt/01-neo-swiss-billboard.jpg`）。
- **借的是什么**：只借「顶部 1px 贯通黑线 + 半屏巨数/主图压小字 + 底部无框标尺 4 列数据带」的信息秩序，标题/正文反差 > 4:1，零圆角卡片。
- **不借的、自己长的**：不借原作的纯白底与公交客流题材；底色取暖微灰纸白 `#F7F6F2` 降眩光，主强调色取蓝队钴蓝 `#1A4BFF` 与阈值熔岩红 `#E8451E`。
- **主角素材**：封面右侧 48% 全出血 `OldQuarter` NavMesh 俯瞰图；共鸣页右侧精密瑞士标尺级跃迁曲线图 + 底部 4 组 `76px` 巨数。
- **骨架**：封面左右 52%/48% 刀切非对称；共鸣页上下二段（上 42/58 断言与跃迁图，下 4 列无框标尺数据）。
- **胆量花在哪**：封面 `132px` 粗黑主标题与全出血地图直撞；共鸣页 `150` 阈值熔岩红竖直标尺切穿全图。
- **form 来自内容的哪里**：《共鸣之境》的核心是「数值越过物理阈值瞬间改写规则」，用瑞士声学标尺与跃迁阶梯表达精确的工程阈值感。

### 方向 2（dir-2）：暗场共鸣波形剧场 · 游戏发布会感
- **逻辑与来源**：现实参照（Nancy Duarte《Resonate》Sparkline `ppt/14-narrative-sparkline.jpg` × Linear `ppt/10-dark-hairline-terminal.jpg`）。
- **借的是什么**：只借「1px 发丝呼吸框线 + 横贯全屏的振荡曲线 + 关键波峰/波谷原位标注 + 冷转暖的叙事转折」。
- **不借的、自己长的**：不借 Linear 紫蓝荧光，不借剧场复盘的时间轴；暗场底 `#0B0E14` 与火海橙 `#FF5A1F` 直接采自 `shot_4_1_resonance_effects.png` 的火焰爆发与暗部枪身。
- **主角素材**：封面以渐变暗角融入高共鸣火海实机爆发画面；共鸣页横贯 `1920px` 的共鸣振荡波形本身作为唯一主角。
- **骨架**：封面电影级全屏暗场 + 底部 4 栏发丝终端元数据；共鸣页上标题 + 中部 65% 全幅振荡剧场 + 底部单行基准注脚。
- **胆量花在哪**：共鸣页砍掉一切卡片与表格，让一条由冷蓝燃成炽橙的振荡波独自撑起整屏张力。
- **form 来自内容的哪里**：「共鸣」本身就是声波与能量的共振曲线，越过 150 临界线从常规对抗爆发为火海与陨石。

### 方向 3（dir-3）：同心共鸣力场 · 东亚建筑出版物图谱
- **逻辑与来源**：秒数轮盘 East #08（`east/08-sugiura-info-mandala.jpg` 杉浦康平信息曼茶罗）× 最佳设计师（吕敬人书籍竖排节奏）。
- **借的是什么**：只借「同心多环信息盘 + 外环精密角度引出线 + 竖排大字书脊」的信息组织机制。
- **不借的、自己长的**：不借原作纯黑夜观底色与节气天文题材；底色改为建筑设定集暖石纸 `#EFECE6`，配色取印刷朱砂 `#C83E2B` 与河道靛青 `#1F4B6E`。
- **主角素材**：封面左侧 `126px` 竖排「共鸣之境」书脊 + 右侧 1px 墨框晴天持枪实机图与准星刻度；共鸣页中央直径 `760px` 四环同心共鸣力场图谱。
- **骨架**：封面左竖排书脊 28% + 右画框与三栏印刷署名 72%；共鸣页左导语/实测 + 中央同心力场盘 + 右 5 条引线注释。
- **胆量花在哪**：封面大胆使用竖排巨型中文书脊配极细朱砂准星；共鸣页用单一几何曼茶罗盘统摄全部输入权重与五类响应。
- **form 来自内容的哪里**：《共鸣之境》以单一 `rr.resonance` 为圆心向四周辐射五类战场响应，天然契合同心圆辐射拓扑。
