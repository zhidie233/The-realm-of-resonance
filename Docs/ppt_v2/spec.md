# 《共鸣之境》实训结题答辩 PPT 设计规格（Spec）

- **项目名称**：《共鸣之境》（THE REALM OF RESONANCE）
- **使用场景**：小组实训结题答辩（现场大屏投影 + 后期可编辑 `.pptx` 微调）
- **画布尺寸**：`1920 × 1080`（16:9 宽屏，三方向完全一致）
- **封面必含信息**：
  - 副题：基于 Unity 的联机第一人称射击游戏实训结题答辩
  - 院校专业：福建师范大学协和学院 · 信息技术系 · 数字媒体技术专业
  - 小组成员：吴凯东（程序框架设计） / 杨世杰（业务逻辑实现） / 周欣琦（美术、策划、测试）
  - 指导教师：黄取治
  - 日期：2026 年 11 月
- **共鸣核心页必含事实数据**：
  - 结算中枢：`MasterClient` 房主结算写入房间属性 `rr.resonance`，全端回调同步
  - 输入权重：命中敌方 `+1` / 误伤友方 `−1`；增幅器 `+2` / 抑制器 `−2`；夺旗 `+10` / 交旗 `+20` / 归还 `−5`
  - 五类响应：
    1. 重力调制（`GravityManager`）：跳跃初速曲线映射（实测 `5.00 → 5.96 → 11.00`）
    2. 地面火海（`GroundFireManager`）：阈值 `150` 激活 `46` 处火点，降至 `100` 销毁
    3. 战区空投（`SupplyManager`）：每跨越 `200` 投放一次补给箱
    4. 第三阵营（`RobotManager`）：每跨越 `1000` 刷出中立机器人
    5. 陨石打击（`MeteoriteFacility`）：击中设施召唤陨石（速度 `20`，基础伤 `50 × 1~3` 倍）
  - 实测性能：`67.7 FPS`（46 火海与 AI 并发平均帧率）、`0 次`（360 帧 Gen0 GC 增量）、`310` 一方脚本 / `44,039` 行代码
