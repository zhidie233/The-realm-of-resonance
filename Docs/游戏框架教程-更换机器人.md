# 游戏框架教程：更换机器人

## 机器人名称

### CoverPoint

游戏框架的 AI 系统支持掩体点。**掩体点是按策略分布在地图中的点位，可优化 AI 的导航寻路**。机器人会根据战场情况利用这些点，为自身行为增加随机性，用于躲避敌人或作为随机移动目标。
 
这些点位推荐使用但并非必需。地图中掩体点越多，机器人的行为就越随机、导航也越自然。
 

**添加新的掩体点**

 
添加掩体点只需复制一个现有点位，再手动摆放到地图中。
 
为便于预览所有掩体点，可在 ***地图场景层级 ➔ AIManager ➔ AICoverPointManager ➔ Show Gizmos*** 中开启辅助显示。

每个掩体点都必须挂载 **AICoverPoint** 脚本，否则不会作为掩体点生效，该脚本在检视面板中有几个公开属性：

- **下蹲**（bool）：机器人使用该掩体点时是否下蹲或起身

- **邻近掩体点**（List）：邻近的掩体点列表，当该掩体点被占用时作为备用。

### AICoverPointManager

脚本 **AICoverPointManager.cs** 挂载于每个 ***地图场景 ➔ AIManager ➔ AICoverPointManager*** 下，负责掩体点的选择逻辑，当机器人请求掩体点时，该脚本会根据请求机器人的状态决定场景中使用哪个掩体点。

该脚本在检视面板中有若干可调公开属性：

- **最大距离**（float）：达成邻近关系的掩体点之间的最大距离。

- **占用时间**（float）：掩体点被使用后再次可用的冷却时间。

- **显示辅助线**（bool）：在地图中显示每个掩体点的辅助线框。

- **烘焙邻近点**（Button）：自动计算场景中每个掩体点的邻近掩体点，每次编辑场景掩体点后都应执行一次。

- **对齐到地面**（Button）：自动调整掩体点的垂直位置，使其紧贴正下方地面而不悬空。

### BotsName

机器人名称从一份预设名称列表中随机选取，作为开发者你可以方便地修改。
 
首先可以定义随机名称的前缀，默认为 **BOT**，可在 GameData ➔ **Bots Name Prefix** 中改成任意内容。
 
要修改随机名称列表，打开脚本 **GameTexts.cs** ➔ **RandomNames**，在该列表中增删或编辑任意一项即可。
