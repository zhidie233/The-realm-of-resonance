## 二、第5章多端联机与URP性能测试所需实测采集项

请按以下场景运行测试并将 Unity Profiler 截图或导出的具体数值回传，用于填充第5章表5-1与表5-2：

1. **多客户端联机功能验证**：通过 Unity Editor 与桌面端构建程序双开或两台终端连接同一 Photon 房间，依次测试团队竞赛、自由混战、夺旗模式、AI补位与真人顶替、共鸣增幅/抑制、高共鸣触发火海/中立AI/空投/陨石、以及房主中途退房后的主机迁移。
2. **Profiler 性能采样一，大厅与静止加载态**：进入 `OldQuarter` 对局站立不动无交火状态，记录 FPS、CPU 主线程耗时毫秒数、Draw Call 与 SetPass Calls、Total Allocated Memory。
3. **Profiler 性能采样二，高强度交火与高共鸣并发态**：在 `OldQuarter` 开启AI机器人并推进共鸣值激活地面火海与中立AI后持续连射开火，对比开启与关闭 URP 后处理即 SSAO、Bloom 与 MotionBlur 两种画质条件下的平均帧率、1% 低帧率、Draw Call 数量以及子弹对象池 `ObjectRecycler` 运行期间单帧 GC Alloc 字节数。
4. **网络延迟与同步观测**：开启房间内 Ping / NetGraph 或记录 Photon RTT 延迟毫秒数值，观察双开窗口下远程角色位移与开火动作同步延迟。
