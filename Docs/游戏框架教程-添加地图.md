# 游戏框架教程：添加地图

## 地图资源

### DrawStarted

> 本教程将逐步讲解如何为游戏框架游戏添加新地图。

首先，你当然需要一张地图。这里的地图指的是关卡环境设计，包含所有美术内容，模型、预制体、灯光、天空等，摆放成战场的样子。

地图有一些基本要求，是所有 Unity 用户都应了解的，适用于所有游戏而不仅是游戏框架：

-**地图模型网格必须带碰撞体**，仅作装饰的模型除外。场景中玩家不该穿过的所有模型网格都必须有碰撞体。

-**灯光**，灯光是地图的重要组成部分，但对游戏性能影响很大。网上有大量关于搭建场景灯光和烘焙光照贴图的教程，例如：
https://learn.unity.com/tutorial/introduction-to-lighting-and-rendering#（https://learn.unity.com/tutorial/introduction-to-lighting-and-rendering#）

-**性能优化优先于画面效果**。人人都喜欢游戏有好的画质，但优化不佳的关卡会毁掉你的游戏。游戏框架在代码层面已做了不错的优化，但比代码更重要的是图形优化。Unity 官方有一篇不错的图形优化文章，值得一看：
https://docs.unity3d.com/Manual/OptimizingGraphicsPerformance.html（https://docs.unity3d.com/Manual/OptimizingGraphicsPerformance.html）

好，如果你的地图关卡设计已就绪，我们继续。

### DrawSetup

如前所述，你需要准备好新地图设计，但不能只做成预制体，而要**放置在一个只包含地图环境的 Unity 场景中**。如果没有，请在编辑器顶部菜单 ➔ **File ➔ New Scene** 新建场景，然后在打开的空场景中放入地图环境或直接在其中设计。
                 
准备好后，在 Unity 工程中保存该场景**（File ➔ Save）**，然后继续下一步。

> **在接入游戏框架之前，请务必删除地图场景中的所有相机**。这里不需要它们，游戏框架会创建所需的相机。

在下方字段中指定你的 Unity 地图场景*（.scene）*，**然后点击继续**按钮进行场景校验。

地图场景已打开，现在拖入游戏框架所需的对象。先检查场景中已有的资源，点击下方按钮自动检测。

场景尚未正确配置，点击下方按钮自动添加所需组件。

一切正常，场景已包含全部所需对象，继续下一步。

实例化游戏框架对象后，你会在 Game 视图中看到一个从顶部渲染的相机，这是玩家进入房间选择阵营时显示俯视角的相机。请将它摆放到能俯瞰地图全貌的位置。
 
该相机位于*（层级面板）**GameManager ➔ Room Camera***。

地图中有一些对象需要重新摆位，其中两个是 CTF 模式的两面旗帜，位于层级面板中的 **GameModes -> CaptureOfFlag** 对象下， 选中它们并摆放到你想要的位置。

对 **ItemManager** 下的对象做同样处理，将它们分布到地图各处。这一步可选，这些物品（医疗包和弹药）可作为地图中的常驻补给品。这样玩家就能在游戏中使用它们。若不需要，直接从场景中删除即可。

现在需要为每个阵营创建**出生点***（阵营 1、阵营 2 以及混战模式）*。出生点并不是固定位置，而是一个**球形区域**，玩家会在该区域半径内的随机位置出生。
 
**如何创建出生点：**
 
在场景中新建一个空物体，挂载 **SpawnLocation.cs** 脚本，并指定区域和阵营。
 
为方便操作，下方提供了一个创建出生点的按钮，选择阵营后点击 **创建出生点** 按钮 ➔ 即可创建出生点，然后在场景视图中选中它并摆放位置。

用上方按钮可创建任意数量的出生点。确保每个阵营至少有一个出生点，完成后继续下一步。

要让 AI 机器人在这张地图上工作，需要设置并烘焙 **导航网格表面**。简单来说，导航网格表面就是允许 AI 智能体移动的区域，Unity 烘焙时会根据地图几何结构自动计算该区域，但你需要设置参与烘焙的网格。关于 Unity 导航网格的深入说明和手动设置方法，请查阅官方文档：

机器人可自由移动的区域由蓝色叠加网格标识。要让机器人发挥最佳效果，必须策略性地摆放 **AI 掩体点**。掩体点是挂载 **AICoverPoint** 脚本的空物体，作为机器人战斗时寻找掩体的参考位置。
 
为简化流程，AIManager 对象已内置一组默认 AI 掩体点。在 Unity 编辑器的层级面板中展开 **AIManager ➔ *** 即可找到它们，可随意微调位置或增加掩体点，以提升机器人寻找掩体时的战术判断能力。

数量可自行决定，不需要那么多就删掉一些，需要更多就复制。

### DrawTips

**优化**

正如开头所说，若希望游戏在同一地图中超过 8 名玩家时仍保持良好帧率，你需要优化地图的图形内容，包括模型、贴图、着色器等。这在单机游戏中不那么关键，但在多人游戏中，本地客户端既要处理本地信息，也要处理从远程玩家收到的信息。因此优化极其重要。
