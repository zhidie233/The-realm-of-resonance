# 中文学术论文 AI 痕迹字典

基于真实 AIGC 检测报告中命中的中文模式整理（尤其是中文摘要 100% 命中的典型机翻学术腔）。

---

## 1. 机翻学术腔 ⭐ 头号杀手（最常见、最致命）

### 识别特征
中文摘要/引言里"翻译过来的句式"——本质是英文学术句式直接套到中文上：

| 机翻句式 | 中文自然句式 |
|---------|-------------|
| 本文以 X 为框架 | 本文借助 X / 沿用 X 的思路 |
| 选取 Y 为研究对象 | 以 Y 为对象 / 聚焦 Y |
| 对 X 进行系统对比 | 系统对比 X / 把 X 放在一起看 |
| 本研究采用 X 与 Y 的研究方法 | 本研究用 X 和 Y 的方法 |
| 研究发现，X 具有 Y 特征 | X 呈现 Y 的特点 |
| 本文认为，X 各有所长 | 两者各有取舍 |
| 旨在通过 X 实现 Y | 想通过 X 做到 Y |
| 从而为 X 提供借鉴 | 给 X 一些参考 |

### 修复策略
- 还原成中文自然语序（主谓宾顺序）
- 避免"对...进行..."的英式动名词结构
- 一段里"本文/本研究"出现不超过 1 次
- 用具体动词替换"进行/实施/开展/展开"

### 改写示例

❌ 原文（100% AI）：
> 本文以彼得·纽马克的交际翻译理论为框架，选取杨宪益、戴乃迭译本（1972）与威廉·莱尔译本（1990）为研究对象，从宏观策略与微观文本两个层面进行对比分析。

✅ 改写：
> 本文借助纽马克的交际翻译理论，对比 1972 年杨宪益—戴乃迭译本与 1990 年莱尔译本，分别从宏观策略和微观文本两个层面切入。

## 2. 形容词/评价词堆砌

### 识别特征
- `具有重要意义`
- `具有深远影响`
- `起到了关键作用`
- `彰显了 X 的独特价值`
- `不可忽视的地位`
- `具有重要的理论价值与现实意义`

### 修复策略
**具体化或删除**。问自己：影响到底是什么？关键作用具体是什么？要么用具体事实替换评价词，要么直接删除。

### 改写示例

❌ 鲁迅《狂人日记》对中国现代文学的发展具有重要意义。

✅ 鲁迅《狂人日记》是中国第一篇白话小说，发表于 1918 年《新青年》。

(用具体事实替换评价词)

## 3. 四字格 AI 套路

### 识别特征
AI 中文学术写作特别爱用对仗工整的四字结构：
- `系统全面` / `深入透彻`
- `兼具 X 与 Y`
- `X 与 Y 并重`
- `忠实保留` / `异化归化`（虽然后者是术语，但成对出现要警惕）
- `相辅相成` / `相得益彰`
- `层层递进` / `环环相扣`

### 修复策略
- **拆开对仗**，只留信息量大的一半
- 或把抽象四字格替换成具体描述

### 改写示例

❌ 两种译本各有所长，分别服务于不同的翻译目的与读者需求。

✅ 两个译本面向的读者不同：杨译针对国际汉学读者，莱尔译针对美国大众。

## 4. 元描述（中文版）

### 识别特征
- `本章主要探讨/分析/论述...`
- `下文将从以下几个方面展开...`
- `首先...其次...最后...`（机械三段）
- `综上所述`
- `本节将围绕 X 展开`

### 修复策略
**直接删除**。中文学术写作完全可以省略这些过渡。让标题和小节标题承担结构提示功能。

### 改写示例

❌ 本章主要探讨交际翻译理论的起源、基本原则和实践应用。下文将从以下三个方面展开。首先...

✅ （删除元描述段，直接进入第一个具体内容）

---

## 5. 被动腔与"被字句"

中文 AI 写作受英文被动语态影响，会写：
- `被广泛认为是...`
- `被普遍接受为...`
- `X 被 Y 所...`

中文自然写法用主动或者无主句：
- `学界普遍认为...`
- `通常归入...`
- `Y 通常这样处理 X...`

### 改写示例

❌ 该作品被视为中国现代文学的开山之作。

✅ 学界普遍把这部作品视为中国现代文学的开山之作。

（或更自然）✅ 这部作品通常算作中国现代文学的开山之作。

---

## 6. 句尾必加评价

### 识别特征
段落末尾必出现：
- `...具有重要的理论价值与现实意义`
- `...为后续研究提供了参考`
- `...对 X 领域具有借鉴意义`
- `...值得进一步深入研究`

### 修复策略
**直接删除**评价句。学术论文的价值不需要自己宣布。

---

## 7. 空动词 + 名词化

### 识别特征
- `进行分析` → 分析
- `开展研究` → 研究
- `实施改写` → 改写
- `对 X 加以说明` → 说明 X
- `做出贡献` → 贡献

中文 AI 文本喜欢把动作名词化再加一个空动词。

### 修复策略
**直接用动词**，去掉"进行/开展/实施/加以"。

---

## 8. 过度形式化连接词

### 识别特征
- `与此同时`
- `值得注意的是`
- `不难发现`
- `综上所述`
- `换言之`
- `从某种意义上说`
- `在一定程度上`

### 修复策略
- 多数可以直接删除
- 如果需要承接，用更具体的逻辑词：`但是`、`相比之下`（如果真有对比）、`这意味着...`

---

## 9. 高频 AI 中文词汇

### 见到就替换 / 删除

| AI 中文词 | 替换 |
|----------|------|
| 深入 / 深刻 | 删（如"深入研究" → "研究"）|
| 全面 | 删 |
| 系统 | 删（除非真的强调系统性）|
| 整体 / 总体 | 多数可删 |
| 重要 / 关键 / 核心 | 删评价词，说具体事 |
| 充分 / 切实 / 有效 | 删 |
| 助力 / 赋能 / 加持 | 用普通动词替换 |
| 凸显 / 彰显 | 显示 / 表现 |
| 围绕 | 删（如"围绕 X 展开讨论" → "讨论 X"）|
| 旨在 | 想 / 要 / 是为了 |

## 10. 中文摘要专项处理

中文摘要是 AIGC 检测里最容易 100% 命中的，因为它是**英文 abstract 的机翻产物**。

### 处理顺序
1. **完全重写**，不要在原文基础上小改
2. 先用 1-2 句话直接说**研究对象 + 核心发现**（不要先说"本文采用什么方法"）
3. 中间 2-3 句具体说**最有代表性的发现**（带具体例子或对比）
4. 末尾 1 句说**这个发现意味着什么**（不用"具有重要意义"这种空话）
5. 整段不超过 200 字，句长有变化

### 改写示例

❌ 原文（100% AI）：
> 鲁迅《狂人日记》是中国现代文学的开山之作，其英译对中国文学海外传播具有重要意义。目前国内外对《狂人日记》英译的研究多集中于语料库风格分析或异化归化视角，从交际翻译理论角度进行系统对比的研究较少。本文以彼得·纽马克的交际翻译理论为框架，选取杨宪益、戴乃迭译本（1972）与威廉·莱尔译本（1990）为研究对象，从宏观策略与微观文本两个层面进行对比分析...

✅ 改写：
> 《狂人日记》两个主要英译本——1972 年杨宪益—戴乃迭译本与 1990 年莱尔译本——在策略上差异明显。本文借助纽马克的交际翻译理论，从宏观和微观两端对比二者：宏观上看翻译目的、副文本和叙事语体；微观上看文化负载词、隐喻和句法转换。杨译更贴近原文形式，把跨文化跳跃留给读者；莱尔译用地道美式英语重写叙事，靠脚注和扩展说明替读者搭桥。两条路径分别对应不同的读者预设——前者偏汉学研究读者，后者偏一般英语读者。

## 总体改写检查清单（中文版）

- [ ] 机翻句式（以...为框架 / 进行 X 分析）是否还原成中文自然语序？
- [ ] 元描述（本章主要 / 综上所述）是否删除？
- [ ] 评价词（重要 / 深远 / 关键作用）是否替换成具体事实？
- [ ] 句尾评价句（具有重要意义）是否删除？
- [ ] 四字格对仗是否拆开？
- [ ] 空动词（进行 / 开展）是否换成实动词？
- [ ] 被字句是否改成主动或无主句？
- [ ] 一段里"本文/本研究"是否不超过 1 次？
- [ ] 引用、术语、数据是否完整保留？
