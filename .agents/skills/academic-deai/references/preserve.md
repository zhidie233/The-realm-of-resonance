# 学术写作必须保留的特征清单（红线）

无论为了降 AI 率怎么改，下面这些**绝对不能动**。改之前一定先过一遍这个清单。

---

## 1. 引用与文献（绝对红线）

- `(Author, Year)` 格式的所有引用
- 中文引用 `(作者, 年份)` 或 `（作者, 年份）`
- 直接引用文本 `"..."` 或 `「...」`或 `『...』`
- 页码 `(p. 23)` / `(pp. 23-45)` / `(第 23 页)`
- 脚注 / 尾注内容
- 参考文献条目
- DOI、URL、ISBN

**注意**：即使引用句子的措辞像 AI，也只能改引用句**外**的部分。引用本身是事实陈述，改了就是学术不端。

---

## 2. 学术语态（保留 hedging）

学术写作必须保留对冲措辞，不能为了"显得肯定"改成绝对化：

**英文 hedging（保留）**：
- `may / might / could`
- `suggest / appear to / seem to`
- `it is possible that` （可以改短，但不能删 hedging 含义）
- `in some cases / for the most part / generally`
- `tends to / is likely to`

**中文 hedging（保留）**：
- `可能 / 或许 / 似乎`
- `倾向于 / 大致 / 多数情况下`
- `一定程度上`（这个虽然是 AI 高频词，但在表达 hedging 时保留）
- `通常 / 一般来说`

### 为什么
学术论文里 hedging 是规范。删掉反而显得不专业，而且不能反映作者对结论确定性的判断。把 "Newmark suggests that..." 改成 "Newmark proves that..." 是事实错误。

---

## 3. 方法论部分的被动语态

Methods 章节按学科惯例使用被动语态——**保留**：

- `The data were collected from...`
- `Participants were recruited via...`
- `A comparative analysis was conducted...`
- `The texts were analyzed using...`
- 中文："数据采自..."、"对样本进行了..."

不要为了"降 AI 率"把方法描述全改成主动。检测系统对学科规范有一定容忍度，但读者（导师/评审）不会容忍方法部分写得像散文。

---

## 4. 术语 / 理论概念

不要替换：
- 翻译研究术语：`communicative translation / semantic translation / foreignization / domestication / skopos / equivalence`
- 语言学术语：`parataxis / hypotaxis / register / discourse / paradigm`
- 中文术语：`交际翻译 / 语义翻译 / 异化 / 归化 / 等值`
- 已经引用过原作者的概念名
- 学科内通用的专有名词

即使这些词看起来像 AI 高频词，在学术语境里它们是技术术语。

---

## 5. 数据与事实

绝对不动：
- 数字、年份、统计数据
- 人名（中外作者、人物）
- 地名、机构名
- 引用的文本片段（中文原文、外文原文）
- 检测报告里的具体数据
- 表格、图表里的数据

---

## 6. 论证逻辑

不能改变的：
- 因果关系的方向（"A 导致 B" 不能改成 "B 导致 A"）
- 对比关系的本质（"X 比 Y 更 Z" 不能改成相反）
- 作者的核心观点
- 研究问题本身
- 文献综述里其他学者观点的归属（A 说过的话不能改成 B 说的）

---

## 7. 学科特定规范

### 翻译研究
- 原文 / 译文对照引用格式必须保留
- 译者名字必须用学界通用拼写（Yang Hsien-yi 不能改成 Yang Xianyi 除非论文里用的就是后者）
- 译本年份是事实

### 文学研究
- 作品名 / 篇章名（如《狂人日记》/ A Madman's Diary）格式不变
- 角色名、章节标题不变

### 语言学
- 例句编号 `(1) (2) (3)` 不变
- 语料标注、glossing 不变

---

## ⚠️ 终极红线

**不能凭空生成内容**：

如果用户原文里没有具体例子、没有具体引用、没有具体数据，**不要为了"加锚点降 AI 率"而编造**。

应该的做法：
- 标注 `[此处建议补充：可引用 Newmark (1988) p.40-41 的定义]`
- 标注 `[此处建议补充原文中文/英文片段]`
- 标注 `[需要补充具体页码]`

让用户自己去查、自己去加。**学术不端的代价远大于 AI 检测分数。**

---

## 改写完最后自检

每次改写完，过一遍：

1. ✅ 所有引用是否完整且位置正确？
2. ✅ hedging 是否保留？没有把 "may" 改成 "is"？
3. ✅ 方法部分的被动语态是否保留？
4. ✅ 术语是否一致？没有把 "foreignization" 改成同义词？
5. ✅ 数字、年份、人名是否一字未动？
6. ✅ 论证方向是否一致？没有改变作者本意？
7. ✅ 是否凭空添加了原文不存在的内容？（不应有）
